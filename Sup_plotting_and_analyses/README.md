# Supplementary plotting and analyses

This directory contains the active scripts for the retained **supplementary figure** plotting workflow.

## Active scripts

1. `sbge_metric_plots.R`  
   Writes the SBGE-stratified metric plot-data and permutation-test tables kept in `Data/Summary_tables/SBGE_supplement/`.

2. `figureS2_sa_mag.R`
   Builds the single-panel `Sup_figures/FigS2_sa_mag.png` SA-effect comparison stratified by whole-body sex-biased gene expression.

3. `figureS3_context.R`
   Builds the single-panel `Sup_figures/FigS3_sa_mag_context.png`, comparing SSDOs with Innocenti and Morrow (2010), Grieshop et al. (2025), and Ruzicka et al. (2019) candidates using per-gene maximum Ruzicka Wald statistics. Grieshop candidates are the 695 `Sig == TRUE` genes in `Data/inputs/DE.summary.tsv`; 530 have protein-coding, SNP-mapped estimates. Candidate groups may overlap. Horizontal blue/green/grey reference lines retain the original Fig1 bootstrap means for disease orthologues, orthologues, and background. The script exports `FigS3_gene_level_values.csv`, `FigS3_bootstrap_summaries.csv`, `FigS3_reference_lines.csv`, and `FigS3_Grieshop_candidate_audit.csv` to `Data/Summary_tables/`.

4. `figureS5_figureS6_metric_panels.R`
   Builds:
   - `Sup_figures/FigS5_rmf_tau.png`
   - `Sup_figures/FigS6_rlns_tajD_DoS.png`

5. `figureS7_radar_context.R`
   Builds `Sup_figures/FigS7_SSDO_candidate_overlay.png`, the study-matched single-panel overlay comparing SSDOs with Innocenti, Ruzicka, and Brigos-Baril et al. (2026) candidate sets. It exports `FigS7_SSDO_candidate_overlay_multivariate_test.csv`. Candidate sets can overlap and retain the same study-matched per-feature denominators as Fig4.

The SBGE-stratified component PNGs are no longer kept as tracked standalone outputs.

`FigS1` and `FigS4` are generated by the corresponding scripts in `Plotting_and_analyses/`.
