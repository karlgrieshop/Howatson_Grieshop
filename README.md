# Final Year Project — Sex-Specific Disease Orthologues in *Drosophila melanogaster*

Analysis code for a study comparing the evolutionary and genomic properties of sex-specific disease orthologues (SSDOs) in *Drosophila melanogaster* against broader disease-gene orthologues, all orthologues, and the genomic background.

## Overview

Human genes implicated in sex-specific diseases were converted to their *D. melanogaster* orthologues (SSDOs). Their gene-expression profiles (sex-biased gene expression, SBGE) and population-genetic signatures were compared across four categories:

| Category | Description |
|---|---|
| **SSDOs** | Orthologues of sex-specific disease genes (the focal set) |
| **All Disease Orthologues** | Orthologues of any disease gene (OMIM-derived) |
| **All Orthologues** | All confirmed human–fly orthologues |
| **Background** | Genome-wide reference (autosomes + X/Y; disease genes excluded) |

## Scripts

| Script | Purpose |
|---|---|
| `Final_Script.R` | Main analysis: imports SBGE/population-genetics data, builds control and disease gene sets, computes bootstrap summaries for the 2-group (Disease vs Background) comparison |
| `data_analysis.R` | Extended analysis: multi-tissue SBGE, tissue-specificity, all summary tables for the 4-way comparison |
| `Candidate vs Ortholog and Disease genes.R` | Assembles all four gene-type groups, runs permutation tests, produces the main comparison plots |
| `Plotting (Genomic Metrics, All).R` | Standalone plotting script that reads pre-computed Summary Table CSVs |
| `SA magnitude.R` | Sexually antagonistic SNP annotation via BioMart |

## Key Data Sources

| Dataset | Reference | Use |
|---|---|---|
| `Sex.Biased.Genes.Whole.csv` | Mishra et al. 2024 | Whole-body SBGE (log₂FC, sex-bias category) |
| `FileS7.txt` | Fraisse et al. 2018 | Tissue-specificity index (`tissueSpecificityAdults`), McDonald–Kreitman statistics (DoS, Ps/Pn/Ds/Dn) |
| `SBGEandSSSdataForMBE.csv` | Singh & Agrawal 2023 | Population-genetics metrics (Tajima's *D*, rMF, πN fraction, rlnd) |
| `GeneLists/*.tsv` | FlyBase | Chromosome-level gene lists used to define the genomic background |

## Known Issues / Regeneration Required

> **Tissue Specificity Background SampleSize (CSV)**  
> The pre-computed `Summary Tables/Tissue Specificity Plot Data.csv` contains `Background SampleSize = 15,927`, which is ~3× the expected value (~5,309). This occurred because an earlier run of the analysis accidentally used all-three-tissue SBGE data (gonads + heads + whole bodies) when building the background gene set for the tissue-specificity analysis, causing each background gene to appear once per tissue with a distinct `exp_SBGE_ase` value and thereby surviving the downstream `distinct()` call.  
> The code has been fixed (`filter(Tissue == "Whole Body")` added + `stopifnot()` assertion). **The Summary Table CSVs must be regenerated** from the corrected scripts before the tissue-specificity plot is used in a publication.
