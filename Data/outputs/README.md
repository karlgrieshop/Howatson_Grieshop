# Data/outputs

This directory contains the **active compiled intermediate tables** used by downstream scripts.

## Kept outputs

- `dmel_gene_reference.csv`, `dmel_transcript_reference.csv`  
  Local reference tables built from the Ensembl/FlyBase GTF.

- `sexspecific_disease_gene_data.csv`, `sexspecific_disease_ids.csv`, `all_disease_ortholog_ids.csv`, `all_ortholog_ids.csv`  
  Canonical SSDO, disease-orthologue, and orthologue gene sets used throughout the repository.

- `mishra_whole_body_sbge_bins.csv`  
  Active whole-body SBGE classification used in the current figure set.

- `Affx_Dros_2.0.csv`  
  Probe-to-gene map used to define the Innocenti and Morrow (2010) assay universe for FigS1.

- `sa_resolution_feature_membership.csv`, `sa_resolution_feature_sets.csv`, `sa_resolution_feature_universes.csv`  
  Study-matched Fig4 input tables describing mechanism membership, the TRUE gene sets, and the per-feature source-study universes after the current SA-resolution wrangling. FigS9 uses the `MB`/`TS` and `HMB`/`HTS` membership flags to define its two stages. `SSS` now uses the locally supplied `Mishra.sig.SSS_filt25.txt` tested-gene frame together with the DsRed-restored final list in `dimorphic.subset.list_wDsRedgenes.txt`, while `Dup` remains the only protein-coding-genome fallback.

These tables are intended to be regenerated by the active `Data_wrangling/` scripts.
