# Summary tables

This directory contains retained figure data and statistical results. Files
named `FigS7_*` report fly–human conservation results; `FigS8_*` report the
conservation-adjusted SA analysis; and `FigS9_*` report resolution-stage
analyses. Other tables support the main figures, supplementary figures, and
manuscript tables.

SA-effect tables use the maximum absolute Wald statistic per gene:
`max(abs(Wald_Stat))`, with absolute values taken before the maximum and no
squaring. Table-generation scripts are in `Tables/`.
