# Data

This directory contains the repository's retained data products and local input staging area.

## What is here

- `outputs/` contains active compiled intermediate tables generated by the wrangling scripts and used by downstream analyses and plotting.
- `Summary_tables/` contains the kept summary/statistical tables used to report results and, in several cases, to rebuild manuscript figures directly.

## What is not kept here

- `inputs/` is not tracked in the repository. Populate it locally with the accession files required by the workflow.

For the current accession location, input provenance, and rerun instructions, see the [top-level README](../README.md).
