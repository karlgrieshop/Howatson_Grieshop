# Data Directory

## Input Files

### SBGE & Population-Genetics Data

| File | Description | Source |
|---|---|---|
| `Sex.Biased.Genes.Whole.csv` | Whole-body sex-biased gene expression. Columns include `FlyBaseID`, `log2FoldChange` (♂/♀ expression ratio), `Sex.Bias.Category` | Mishra et al. 2024 |
| `FileS7.txt` | Gene-level population-genetics and expression summary. Key columns: `geneId` (FlyBaseID), `tissueSpecificityAdults`, `DoS`, `Ps`, `Pn`, `Ds`, `Dn`, `piN`, `piS`, `tajD.S`, `recomb` | Fraisse et al. 2018 |
| `SBGEandSSSdataForMBE.csv` | Whole-body and head SBGE, population-genetics stats. Key columns: `geneID` (FlyBaseID), `tajD.S`, `rmf`, `piNfract`, `DoS` | Singh & Agrawal 2023 |
| `SBGE_disease_data.csv` | Pre-merged disease-gene SBGE table (disease genes × Mishra whole-body); generated by `Final_Script.R` | This project |
| `mish_fra_SBGE.csv` | Pre-merged disease-gene SBGE × Fraisse table; generated by `Final_Script.R` | This project |

### Disease Gene Lists

| File | Description |
|---|---|
| `all_disease_genes.csv` | FlyBase IDs for all OMIM-derived disease-gene orthologues |
| `all_orthologs.csv` | FlyBase IDs for all confirmed human–fly orthologues |
| `diopt_results*.csv` | DIOPT orthology results for individual diseases (PCOS, spinal-cord/brain tumours, etc.) |
| `alzheimer_disease_orthologs.csv`, `coronary_artery_disease_orthologs.csv`, etc. | Literature-search disease orthologue files |
| `*.txt` (in data root) | FlyBase gene-ID lists from FlyBase disease-name searches (one disease per file) |

### Gene Lists

The `GeneLists/` subdirectory contains FlyBase chromosome-level gene lists used to define the genomic background:

| File | Chromosome | Header? |
|---|---|---|
| `X.chromosome.genes.tsv` | X | **No** (read with `header=FALSE`) |
| `Y.chromosome.genes.tsv` | Y | **No** (read with `header=FALSE`) |
| `2L.chromosome.genes.tsv` | 2L | No |
| `2R.chromosome.genes.tsv` | 2R | No |
| `3L.chromosome.genes.tsv` | 3L | No |
| `3R.chromosome.genes.tsv` | 3R | No |
| `all.genes.tsv` | All | No |

> **Note**: An earlier version of the scripts incorrectly read the X and Y chromosome files with `header=TRUE`, which caused the first gene on each chromosome to be silently dropped (treated as column name). This has been fixed to `header=FALSE` in all scripts.

### Summary Tables

Pre-computed bootstrap summary CSVs for the main four-way comparison plots. Columns: `GeneType`, `q05` (2.5th percentile), `q50` (median), `q95` (97.5th percentile), `SampleSize` (sum of per-SBGE-bin counts = total genes across all five sex-bias bins).

| File | Metric | Notes |
|---|---|---|
| `tajD Plot Data.csv` | Tajima's *D* (synonymous sites) | Background n ≈ 12,324 ✓ |
| `rMF Plot Data.csv` | Male-to-female fitness ratio (rMF) | Background n ≈ 10,155 ✓ |
| `DoS Plot Data.csv` | Direction of Selection (DoS) | Background n ≈ 10,196 ✓ |
| `rlnd Plot Data.csv` | Relative level of nonsynonymous diversity | Background n ≈ 12,085 ✓ |
| `Tissue Specificity Plot Data.csv` | Adult tissue-specificity index | **Background n = 15,927 — INFLATED ⚠️** |

> **⚠️ Tissue Specificity Background is inflated**: The CSV records Background `SampleSize = 15,927`, which is ~3× the expected ~5,309. Root cause: the CSV was generated using all-three-tissue SBGE data (gonads + heads + whole bodies) for the background, causing each background gene to appear three times with distinct expression values. The code has been fixed. **Regenerate this CSV before publication** by re-running `data_analysis.R` followed by `Candidate vs Ortholog and Disease genes.R`.
