# Manuscript tables

Run the R scripts from the repository root. They generate editable Word tables
from the corresponding retained statistical results in `Data/Summary_tables/`.

- `table1_sa_magnitude_permutation_docx.R` generates Table 1.
- `tableS1_candidate_enrichment_docx.R` generates Table S1.
- `tableS2_candidate_context_docx.R` generates Table S2.
- `tableS6_conservation_permutation_docx.R` generates Table S6.
